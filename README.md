# make-video-dub

用字幕檔幫影片加上**中文字幕**和 **AI 配音**的小工具（Python）。

一鍵幫影片**靜音原聲、燒上字幕、加上 AI 配音**。

你只要寫好一個字幕檔（每句話的開始時間、結束時間和文字），程式就會自動：

1. 用 AI 把每句字幕念出來（微軟 Edge 台灣中文語音，免費）
2. 把語音放到對應的時間點，念不完會自動稍微加速
3. 拿掉影片原本的聲音，換成 AI 配音
4. 用微軟正黑體把字幕燒進畫面下方
5. 輸出一支新影片，**原本的影片不會被改動**

---

## 一、安裝（只需要做一次）

需要 Python 3，然後在終端機執行：

```
python -m pip install -r requirements.txt
```

或直接安裝：

```
python -m pip install edge-tts imageio-ffmpeg numpy
```

專案裡附了一個範例字幕檔 [example.txt](example.txt)，可以拿你自己的影片試試看：

```
python make_video.py 你的影片.mp4 example.txt
```

- `edge-tts`：AI 語音
- `imageio-ffmpeg`：內附 ffmpeg，用來處理影片，不必另外安裝
- `numpy`：處理聲音資料（Anaconda 已內建）

> ⚠ AI 語音要連到微軟的服務，**執行時必須有網路**。
> ⚠ 字幕使用 Windows 內建的微軟正黑體（`C:\Windows\Fonts\msjhbd.ttc`），只能在 Windows 上使用。

---

## 二、基本用法

```
python make_video.py 影片.mp4 字幕.txt
```

例如：

```
python make_video.py 1.mp4 1.txt
```

完成後會產生 `1_配音.mp4`，檔名就是原檔名加上 `_配音`。

---

## 三、字幕檔怎麼寫

用記事本或 VS Code 新增一個 `.txt` 檔，**一行一句**，格式是：

```
開始時間    結束時間    字幕文字
```

範例：

```
# 以 # 開頭的行是註解，程式會忽略
0:01     0:03     跌倒偵測實機演示
0:05     0:14     偵測到人員跌倒發出紅色警報
15       18       跌倒超過十秒發出嚴重警告
19.5     24       偵測到人員自行起來取消警報
```

### 時間的寫法

| 寫法 | 意思 |
|---|---|
| `3.5` | 第 3.5 秒 |
| `0:03.5` | 0 分 3.5 秒 |
| `1:03.5` | 1 分 3.5 秒 |
| `0:01:03.5` | 0 時 1 分 3.5 秒 |

- 欄位之間用空白或 Tab 隔開都可以，空幾格都沒關係。
- 結束時間一定要比開始時間晚。
- 開始時間不能超過影片長度。
- 檔案請存成 **UTF-8** 編碼（VS Code 預設就是）。

### 也可以用 .srt 字幕檔

如果你用其他字幕軟體（例如 Subtitle Edit、Aegisub）做好了 `.srt` 檔，也可以直接使用：

```
python make_video.py 影片.mp4 字幕.srt
```

## 四、AI 讀錯字怎麼辦

遇到破音字讀錯時，可以用這個寫法指定讀音：

```
{字幕顯示的字|AI 要念的字}
```

例如「右上角」的「角」被念成 jué：

```
0.25     3.9      點選右上{角|腳}的紀錄，查看事件紀錄
```

- 字幕畫面顯示：**點選右上角的紀錄，查看事件紀錄**
- AI 實際念的是：點選右上**腳**的紀錄……（念成 jiǎo）

原理是找一個讀音正確的同音字給 AI 念，字幕還是顯示原本的字。

## 五、選項

選項都加在指令後面，可以同時使用好幾個。

| 選項 | 作用 | 預設值 |
|---|---|---|
| `--voice 聲音名稱` | 換配音的聲音 | `zh-TW-HsiaoChenNeural` |
| `--rate +20%` | 語速，`+` 是加快，`-` 是放慢 | `+0%` |
| `--font-size 24` | 字幕大小 | `20` |
| `--margin 10` | 字幕離畫面底部的距離，**數字越小越靠下** | `25` |
| `--no-burn` | 字幕不燒進畫面，改成播放器裡可以開關的字幕軌 | 不使用 |
| `-o 輸出檔名.mp4` | 自訂輸出的檔名 | 原檔名加上 `_配音` |

### 可用的台灣中文聲音

| 聲音名稱 | 性別 |
|---|---|
| `zh-TW-HsiaoChenNeural` | 女聲（預設） |
| `zh-TW-HsiaoYuNeural` | 女聲 |
| `zh-TW-YunJheNeural` | 男聲 |

### 範例

```
# 用男聲
python make_video.py 1.mp4 1.txt --voice zh-TW-YunJheNeural

# 語速加快 20%、字幕往下移
python make_video.py demo.mp4 demo.txt --rate +20% --margin 10

# 字幕大一點，並指定輸出檔名
python make_video.py 1.mp4 1.txt --font-size 24 -o 成品.mp4
```

## 六、配音時間是怎麼對齊的

每一句配音都從你寫的**開始時間**開始念。

程式會先算出這句**最多可以念多久**：從這句的開始時間，一直到下一句的開始時間為止（最後一句就算到影片結尾）。

- **念得完**：照正常速度念。如果比字幕結束時間晚一點念完，字幕會先消失，聲音會繼續念完。
- **念不完**：自動加速到剛好念完，最多加速 **1.6 倍**。
- **加速 1.6 倍還是念不完**：會出現警告，這句的尾巴會和下一句重疊。

AI 語音前後通常有一段空白，程式會自動剪掉，只各保留 0.05 秒，避免浪費時間。

## 七、執行時會看到什麼

```
產生 5 句 AI 配音（zh-TW-HsiaoChenNeural）...
    1. 00:00,250   3.2s  點選右上角的紀錄，查看事件紀錄
    2. 00:04,050   4.4s  事件紀錄會列出每筆事件的時間、嚴重度和狀態
    3. 00:08,600   2.7s  回到主畫面，點選區域設定
    4. 00:11,400   3.4s  區域編輯器可以在畫面上劃分監控區域（加速 1.02 倍）
    5. 00:14,800   3.0s  右邊可以新增、排序和儲存區域
合成影片...

完成：demo_配音.mp4
```

每一行依序是：第幾句、開始時間、配音長度、字幕文字。有加速的句子後面會標示加速幾倍。

## 八、常見問題

**出現「⚠ 第 N 句太長……加速 1.6 倍後仍會蓋到下一句」**
這句話太長，時間不夠念。可以：
- 把這句的開始時間提早，或把下一句的開始時間延後
- 把句子改短
- 整體語速加快，例如加上 `--rate +15%`

**出現「第 N 句配音失敗」**
通常是網路問題。程式會自動重試 3 次，還是失敗的話，請確認網路連線後再執行一次。

**字幕擋到畫面上的重要東西**
加上 `--margin 10`（或更小的數字），讓字幕往下移。

**AI 念錯字**
用 `{顯示的字|念的字}` 指定讀音，請看第四節。

**出現「第 N 行格式看不懂」或「時間寫錯」**
檢查那一行是不是「開始時間 結束時間 文字」三個部分都有，而且時間只用數字、冒號和小數點。

**想改字幕重做**
直接改 `.txt` 檔再執行一次同樣的指令就好，新的影片會覆蓋上一次的輸出。
